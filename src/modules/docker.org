* Docker
Add support for managing Docker containers, images, volumes, networks,
contexts and docker-compose

Docker lives on the leader's uppercase =D= slot (with evil that is
=SPC D=, without it =C-c D=): uppercase, to stay clear of the leader
=d= subtree, which the dap module speaks for.  Binding through
=ep3c-define-key= keeps the chord load-order-proof: a plain
=global-map= =C-c D= binding races the leader map for the =C-c=
prefix and loses in the non-evil regime, whichever module loads
second.

#+begin_src emacs-lisp
  (use-package docker
    :ensure t
    :defer t)

  (ep3c-define-key '(normal visual) 'global
    "D" #'docker)
#+end_src

Use =M-x docker=, select a resource then mark or unmark items using
the following keybindings (for more possibilities, check out [[https://github.com/politza/tablist][tablist]]):

| Binding   | Description          |
|-----------+----------------------|
| =?=       | List actions         |
| =l=       | Configure listing    |
| =m=       | MarkItem             |
| =u=       | Unmark item          |
| =t=       | Toggle marks         |
| =U=       | Unmark all           |
| =s=       | Sort                 |
| =* r=     | Mark items by regexp |
| =<=       | Shink column         |
| =>=       | Enlarge column       |
| =C-c C-e= | Export to CSV        |

*** Editing Dockerfiles
Writing Dockerfiles is made easier with =dockerfile-mode=, which
provides syntax hightlighting, indentation, and command customization.

See [[https://www.rahuljuliato.com/posts/emacs-docker-podman][this article]] for further settings.

#+begin_src emacs-lisp
  (use-package dockerfile-mode
    :ensure t
    :defer t
    :config
    (setq dockerfile-mode-command "docker"))
#+end_src
