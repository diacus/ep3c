#+TITLE: Evil (Vim emulation)
#+AUTHOR: Diacus Magnuz
* Emulate Vim editing style
Evil is an extensible vi layer for Emacs, plus [[https://github.com/emacs-evil/evil-collection][evil-collection]] package
installs a collection of Evil bindings for the parts of Emacs that
Evil doest not cover property by default, such as =help-mode=, =M-x
calendar=, Eshell and more.

See Evil Collection repository for details.

#+begin_src emacs-lisp
  (use-package evil
    :ensure t
    :init
    (setq evil-want-integration t
	  evil-want-keybinding nil)
    (evil-mode 1))

  (use-package evil-collection
    :after evil
    :ensure t
    :config
    (evil-collection-init))
#+end_src

* Evil Org
[[https://github.com/Somelauw/evil-org-mode][evil-org]] package adds key-bindings to Emacs org-mode.

*NOTE:* The evil-org configuration is defined in the [[file:orgmode.org][orgmode module]] to keep
all org-related configuration together.

* Terminal TAB Key Handling
If Emacs runs inside a terminal, =TAB= key might not work as expected
(being bound to =evil-jump-forward= instead of =org-tab= or
=org-cycle=).

*NOTE:* The TAB key handling for terminal mode is defined in the
[[file:orgmode.org][orgmode module]] to keep all org-related configuration together.
