* Node.js REPL
  The [[https://github.com/abicky/nodejs-repl.el][nodejs-repl.el]] program is derived from comint-mode and provides
  the following features.

  * Token completion, same as Node.js REPL
  * File name completion in string
  * Incremental history search
  * Sending JavaScript code to REPL

  #+begin_src emacs-lisp
    (use-package nodejs-repl
      :ensure t
      :after exec-path-from-shell
      :hook ((js-mode . nodejs-repl-minor-mode)))
  #+end_src
