The default formatter set up by apheleia for AWK uses =TAB= characters
to indent the code, I rather using two spaces instead.
#+begin_src emacs-lisp
  (require 'apheleia)

  (with-eval-after-load 'apheleia
    (setf (alist-get 'gawk apheleia-formatters)
          '("sh" "-c" "gawk -f - --pretty-print=- | expand -t 4")))
#+end_src
