#+TITLE: Dired file manager settings
#+AUTHOR: Diacus Magnuz
Use Emacs as a file manager with =dired=. Enable the follwing setting
to copy/move files between distant directories. [[https://emacs.stackexchange.com/questions/5603/how-to-quickly-copy-move-file-in-emacs-dired][Source]].

#+begin_src emacs-lisp
  (setq dired-dwim-target 1)
#+end_src

Hide details by default
#+begin_src emacs-lisp
  (add-hook 'dired-mode-hook 'dired-hide-details-mode)
#+end_src

All the icons for =dired-mode=
#+begin_src emacs-lisp
  (use-package all-the-icons-dired
    :ensure t)
#+end_src
