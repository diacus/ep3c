* Buffer Local direnv Interation
[[https://github.com/purcell/envrc?tab=readme-ov-file][envrc.el]] is a GNU Emacs library which uses [[https://direnv.net/][direnv]] tool to determine
per-directory/project environment variables and then set those
environment variables on a per-buffer basis.

#+begin_src emacs-lisp
  (use-package envrc
    :ensure t
    :init
    (envrc-global-mode)
    :config
    (add-hook 'projectile-after-switch-project-hook #'envrc-reload))
#+end_src
