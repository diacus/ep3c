#+TITLE:Windows settings
#+AUTHOR: Diacus Magnuz

If the operating system is Windows install PowerShell package
#+begin_src emacs-lisp
  (when (member system-type '(ms-dos windows-nt cygwin))
    (use-package powershell :ensure t)
    (use-package kql-mode
      :ensure t
      :config
      (add-to-list 'auto-mode-alist '("\\.kql\\'" . kql-mode))))
#+end_src
