Most of the IDE configuration for C/C++ is taken from [[https://emacs-lsp.github.io/lsp-mode/tutorials/CPP-guide/][this guide]].

Eglot provides LSP support via clangd. The server arguments are configured
in lsp.org.

  (add-hook 'c++-mode-hook 'eglot-ensure)
