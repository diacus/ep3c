* Distribution detection
On GNU/Linux and BSD, the running distribution is read from the
[[https://www.freedesktop.org/software/systemd/man/latest/os-release.html][os-release]] file, the freedesktop.org standard present on every
modern distribution.  It supersedes the legacy =lsb_release= tool,
which is not shipped by all distributions anymore.

The =ID= entry is preferred over =NAME= as the canonical identifier:
it is lowercase, machine oriented, and stable across distribution
flavors (=opensuse-leap=, =opensuse-tumbleweed=, ...).
#+begin_src emacs-lisp
  (defun theme--os-release-field (field)
    "Return the value of FIELD from the os-release file, or nil.
Values may be double-quoted, as allowed by os-release(5).  Falls
back to /usr/lib/os-release when /etc/os-release is missing."
    (let ((file (cond ((file-exists-p "/etc/os-release")
                       "/etc/os-release")
                      ((file-exists-p "/usr/lib/os-release")
                       "/usr/lib/os-release")))
          case-fold-search)
      (when file
        (with-temp-buffer
          (insert-file-contents file)
          (goto-char (point-min))
          (when (re-search-forward
                 (format "^%s=\\(\"?\\)\\(.*?\\)\\1$"
                         (regexp-quote field))
                 nil t)
            (match-string 2))))))


  (defun theme--distro-id ()
    "Return the ID of the running distribution, as a lowercase string.
Nil is returned on non-Linux systems and where os-release is absent."
    (when (member system-type '(android gnu/linux berkeley-unix))
      (let ((id (theme--os-release-field "ID")))
        (and id (downcase id)))))
#+end_src

* Colors for Linux and BSD
Installing Nord theme included in [[https://github.com/doomemacs/themes?tab=readme-ov-file#manually--use-package][doom-themes]] collection.  On openSUSE
distributions the Geeko palette takes precedence, taken from the
[[https://github.com/diacus/openSUSE-Emacs-themes][openSUSE-Emacs-themes]] package, in its dark flavor; switch to
=opensuse-light= in the snippet below for the light one.
#+begin_src emacs-lisp
  (when (member system-type '(android gnu/linux berkeley-unix))
    (let ((id (theme--distro-id)))
      (if (and id (string-match-p "suse" id))
          (use-package opensuse-themes
            :quelpa (opensuse-themes
                     :fetcher github
                     :repo "diacus/openSUSE-Emacs-themes")
            :config
            (load-theme 'opensuse-dark :no-confirm))
        (use-package doom-themes
          :ensure t
          :config
          ;; Global settings (defaults)
          (setq doom-themes-enable-bold t
      	  doom-themes-enable-italic t)
          (load-theme 'doom-nord :no-confirm)))))
#+end_src

* Colors for Windows
According to its author, Nimbus theme is something beautiful, slightly
retro, yet readable and easy on the eyes. See more at [[https://github.com/mrcnski/nimbus-theme][Github.com]].
#+begin_src emacs-lisp
  (when (eq system-type 'windows-nt)
    (use-package nimbus-theme
      :ensure t
      :init
      (load-theme 'nimbus :no-confirm)))
#+end_src

* Doom modeline
The [[https://github.com/seagle0128/doom-modeline][doom-modeline]] is a fancy and fast mode-line inspired by minimalist
design. It is required to have installed a [[https://www.nerdfonts.com/][Nerd Font]] to display this
mode line correctly. If that isn't the case the default mode line is
used instead.

For setting up the font family and face, take a look on [[https://stackoverflow.com/questions/6026713/how-do-i-change-emacs-default-font-size-and-font-type][these
instructions]] from Stackoverflow.

#+begin_src emacs-lisp
  (use-package doom-modeline :ensure t)

  (defun theme--get-default-font-family ()
    "Get default font family."
    (let* ((font   (face-attribute 'default :font))
         (family (and font (font-get font :family))))
      (if (stringp family)
        family
        (format "%s" family))))


  (defun theme--is-default-font-nerd-font-p ()
    "Return non-nil if the default face uses a Nerd Font."
    (let ((family (theme--get-default-font-family)))
      (and family
         (string-match-p
          (regexp-opt '("Nerd Font" "Nerd-Font" "NF"))
          family))))


  (defun theme--doom-modeline-mode ()
    (when (theme--is-default-font-nerd-font-p)
      (doom-modeline-mode)))


  (init--with-ensure-frame-ready #'theme--doom-modeline-mode)
#+end_src
