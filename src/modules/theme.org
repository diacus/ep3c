* Cursor line
By default the cursorline hightlighting is underlined, I don't like it.
#+begin_src emacs-lisp
   (use-package hl-line
     :config
     (set-face-underline 'hl-line nil))
#+end_src

* Colors for Linux and BSD
Installing Nord theme included in [[https://github.com/doomemacs/themes?tab=readme-ov-file#manually--use-package][doom-themes]] collection
#+begin_src emacs-lisp
  (when (member system-type '(android gnu/linux berkeley-unix))
    (use-package doom-themes
      :ensure t
      :config
      ;; Global settings (defaults)
      (setq doom-themes-enable-bold t
  	  doom-themes-enable-italic t)
      (load-theme 'doom-nord :no-confirm)))
#+end_src

* Colors for MacOs
[[https://github.com/emacsmirror/timu-macos-theme][timu-macos-theme]] is inspired by the macOS UI.
#+begin_src emacs-lisp
  (when (eq system-type 'darwin)
    (use-package timu-macos-theme
      :ensure t
      :init (load-theme 'timu-macos t)))
#+end_src

* Colors for Windows
According to its author, Nimbus theme is something beautiful, slihtly
retro, yet readable and easy on the eyes. See more at [[https://github.com/mrcnski/nimbus-theme][Github.com]].
#+begin_src emacs-lisp
  (when (eq system-type 'windows-nt)
    (use-package nimbus-theme
      :ensure t
      :init
      (load-theme 'nimbus :no-confirm)))
#+end_src

* Doom modeline
The [[https://github.com/seagle0128/doom-modeline][doom-modeline]] is a fancy and fast mode-line inspired by minimalist
design.
#+begin_src emacs-lisp
  (when (member system-type '(android gnu/linux berkeley-unix))
    (use-package doom-modeline
      :ensure t
      :hook (after-init . doom-modeline-mode)))
#+end_src
