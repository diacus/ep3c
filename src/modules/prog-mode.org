* Key bindings
Many programming language modes (see [[https://www.gnu.org/software/emacs/manual/html_node/elisp/Derived-Modes.html#Derived-Modes][Derived Modes]] for details) run
=prog-mode-hook= prior running their own mode hooks. So this is a good
place to define settings common for use with any programming language.

Comment toggling is one chord that must adapt to the language of the
buffer it runs in, so it is bound globally to a small dispatcher:
=comment-or-uncomment-region= resolves =comment-start=, =comment-end=
and =comment-region-function= buffer-locally, which makes it toggle
the right syntax per major mode, including =org-mode=, which installs
=org-comment-or-uncomment-region= under it.

In visual state it toggles the selection; in normal state, the
current line.  Without evil the chord that lands on it is
=C-c ;=, which =org-mode-map= shadows locally with =org-toggle-comment=
in org buffers -- the mode-specific command wins where one exists.
#+begin_src emacs-lisp
  (defun ep3c-comment-toggle ()
    "Toggle comments on the region, or on the current line without one."
    (interactive)
    (if (use-region-p)
        (comment-or-uncomment-region (region-beginning) (region-end))
      (save-excursion
        ;; A cursor parked on a trailing empty line targets the real
        ;; last line -- `line-beginning-position' would return that
        ;; empty line itself and the toggle would silently do nothing.
        (when (and (eobp) (/= (point) (point-min)))
          (forward-line -1))
        (comment-or-uncomment-region (line-beginning-position)
                                     (line-beginning-position 2)))))

  (ep3c-define-key '(normal visual) 'global
    ";" #'ep3c-comment-toggle)
#+end_src

* Temp directory per project
Sometimes it is useful having temporary files in the root of the
project, to have the development environment encapsulated.

#+begin_src emacs-lisp
  (defun prog-mode--project-temp-dir ()
    "Use project-local .tmp directory if it exists."
    (when-let* ((project (project-current))
                (root    (project-root project))
                (tmp     (expand-file-name ".tmp/" root)))
      (when (file-directory-p tmp)
        (setq-local temporary-file-directory tmp))))

  (add-hook 'prog-mode-hook #'prog-mode--project-temp-dir)
#+end_src

* Syntax checking
For syntax checking, [[https://www.flycheck.org/en/latest/][Flycheck]] is a modenr on-the-fly syntax checking
extension for GNU Emacs, intended as replacement for the older Flymake
extension which is part of GNU Emacs.
#+begin_src emacs-lisp
  (use-package flycheck :ensure t)

  (defun prog-mode-custom-settings ()
    "Settings for all programming languages"
    (setq flycheck-check-syntax-automatically '(mode-enabled save))
    (setq flycheck-display-errors-delay 0.3))
  
  (add-hook 'prog-mode-hook 'flycheck-mode)
  (add-hook 'prog-mode-hook 'prog-mode-custom-settings)
#+end_src

* Highlight current line
=hl-line-mode= to highlights the cursor line. Then customize the
*Highlight* face to teak the look and feel as you need.
#+begin_src emacs-lisp
  (add-hook 'prog-mode-hook 'hl-line-mode)
#+end_src

* Line numbers
=display-line-numbers-mode= numbers the lines in the buffer. Set
relative numbering by customizing =display-line-numbers-type=
variable.
#+begin_src emacs-lisp
  (add-hook 'prog-mode-hook 'display-line-numbers-mode)
#+end_src
