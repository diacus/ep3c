See the settings [[file:src/modules/*.org][here]].

* Installation
  To install the settings, load =src/install.el= and call =(ep3c--setup)=:

  #+begin_src emacs-lisp :results none
    (load-file (file-name-concat default-directory "src" "install.el"))
    (ep3c--setup)
  #+end_src

* Remove configuration
  To get rid of everything just delete =user-emacs-directory=
  #+name: remove-everything
  #+begin_src emacs-lisp :results none
    (delete-directory user-emacs-directory t t)
  #+end_src

  To delete the settings but keep the rest, only delete =init.el= file
  and =modules= folder.

  #+name: delete-settings-only
  #+begin_src emacs-lisp :results none
    (delete-file (file-name-concat user-emacs-directory "init.el"))
    (delete-directory (file-name-concat user-emacs-directory "modules") t)
  #+end_src
