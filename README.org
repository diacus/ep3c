* Getting Started
  Clone this repository and run the =help= target

  #+begin_src shell
    git clone https://github.com/diacus/emacs-config.git
    cd emacs-config
    make help
  #+end_src

* Installation
  #+begin_src shell
    cd emacs-config
    make install
  #+end_src

* Remove configuration
  #+begin_src shell
    cd emacs-config
    make reset-emacs
  #+end_src

* Syncing your changes
  If for any reason you change the configuration manually or use the
  =customize-variable= or =customize-option= functions you can fetch
  those changes back to this repository by running the =sync= target.

  #+begin_src shell
    cd emacs-config
    make sync
  #+end_src

  After that your local repository will contain the changes from your
  installed configuration, you can inspect them and decide if commit
  or discard them.
